🍛 Requests विरुद्ध limits + QoS classes (धडे 08, 23)

RequestsLimits
उपमावचन दिलेली थाळीदुसऱ्या वाढीवरची मर्यादा
कोण वाचतेscheduler — requests बसतील तिथेच pods ठेवतोkubelet/kernel — चालू असताना लागू करतो
CPU ओलांडले—throttled (हळू, जिवंत)
Memory ओलांडली—OOMKilled 💀
QoS classGuaranteed = requests == limits · Burstable = requests < limits · BestEffort = काहीच नाही — दबावाखाली सर्वात आधी काढला
कधी नाही"सगळे वापरू द्या" म्हणून requests नाहीत — BestEffort, सर्वात आधी बाहेरrequests पेक्षा खूप वरचे limits — over-commit जे शेजाऱ्याला OOMKill करते
