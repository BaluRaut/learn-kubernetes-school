🗓️ The study plan — 26 lessons, 9 weeks

The whole course in sequence, ~3 sessions a week, each session = read one lesson (~15 min) + do its lab (~25 min). Tick lessons off as you go — progress is saved in this browser. Don't rush: the labs are where it sticks.

🐢 Steady (recommended): 3 sessions/week → done in ~9 weeks. Fits around a job.
🐇 Fast track: ~2 hours/day → done in ~2½ weeks. Good between jobs or on break.
💰 Cost: weeks 1–8 are laptop-only (free). Only the optional capstone touches AWS — destroy same day.
