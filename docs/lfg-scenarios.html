🌾 LFG Platform — Scenario & Sequence Diagrams

Companion gallery to the RFC (v4.1): each of the ten production scenarios as its own full-size 4K diagram, followed by three sequence diagrams for the flows reviewers ask about most. The one-page overview poster shows all ten at a glance.

1 · Onboarding a new grower

Ops creates the LFG → one idempotent automation call (silo DB, user, migrations, KMS, S3, secret) → encrypted route id → admin invited via Cropwise Base. Minutes, not days.

2 · Two crops, many varieties — one country

Soybean and corn varieties side by side in the BR-scoped layer; one country's metric rules validate both crops; adding a variety is an insert, not a deploy.

4K PNG · SVG

3 · Two crops, multiple countries

The farm carries the country — BR and US farms share one silo; the same metric key carries per-country rules and units; season windows are date ranges, so hemispheres just work.

4K PNG · SVG

4 · Personas — who sees what

The LFG's admin assigns role + data scope; the query layer appends the scope filter to every silo query. Enforced in SQL, audited, effective ≤ 60 s.

4K PNG · SVG

5 · Zones — stored & fetched

Postgres holds the filterable metrics (with batch_id, supersede-never-edit); S3 holds the geometry dumps, fetched by presigned URL only when a map opens. 20-year history.

4K PNG · SVG

6 · Database — how it works

Many logical grower DBs on pooled Multi-AZ RDS hosts; a small control-plane DB; one catalog-driven migration job with per-silo reporting.

4K PNG · SVG

7 · API ⟷ database connection

CB token + encrypted route → tenant guard 403s first → persona scope attached → a bounded, cached pool for that LFG only. A cross-silo query is unwritable.

4K PNG · SVG

8 · Rate limits & security layers

WAF → per-user/per-LFG throttles → whitelist validation (bad rows → reject + worklist) → immutable audit log. Each layer assumes the one above failed.

4K PNG · SVG

9 · Data encryption

TLS on every hop; KMS key per LFG for RDS and S3; rotated secrets never in code. Offboarding = key deletion makes the silo cryptographically dead.

4K PNG · SVG

10 · Disaster recovery — one grower

The blast-radius ladder: batch rollback (seconds) → single-silo restore (< 1 h) → region rebuild from IaC + cross-region replicas (< 4 h). Other growers never notice.
